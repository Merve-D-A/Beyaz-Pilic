# 🍗 Beyaz Piliç — İleri Web Tasarımı Final Projesi

Mersin'in köklü esnaflarından **Beyaz Piliç** için İleri Web Tasarımı dersi (2025–2026 Bahar Dönemi) kapsamında sıfırdan geliştirilmiş, modern ve performans odaklı kurumsal vitrin web sitesi projesidir.

## 👤 Müşteri Bilgileri & İhtiyaç Analizi
* **Müşteri Adı:** Beyaz Piliç (Mersin)
* **Sektör:** Gıda / Tavukçu / Çiğ Satış &amp; Pişirim
* **Şubeler:** Yenişehir (Kök Şube) ve Mezitli
* **İhtiyaç Tanımı:** İşletme çiğ tavuk satışı, közde pişirim ve gel-al paket sistemiyle hizmet vermesine ve 4 farklı platformda (GetirÇarşı, TrendyolExpress, YemekSepeti Market, MigrosYemek) yer almasına rağmen kurumsal kimliğini, güncel menüsünü ve doğrudan iletişim kanallarını tek bir merkezde toplayan modern bir web vitrinine ihtiyacı vardı. Bu proje ile bu dijital eksiklik giderilmiştir.

---

## 🛠️ Kullanılan Teknolojiler & Standartlar

* **HTML5:** Tamamen semantik etiket hiyerarşisi (`<header>`, `<main>`, `<section>`, `<footer>`).
* **CSS3 & Grid/Flexbox:** Sayfa yerleşiminde `float` veya `table` kullanılmamış; tamamen modern CSS Grid ve Flexbox esnekliği uygulanmıştır. Asimetrik duvar (masonry) galeri yapısı CSS Grid ile kurulmuştur.
* **Vanilla JavaScript:** Köz parçacıklarının yükselme animasyon algoritması (`Math.random()`) ve görselleri büyüten dinamik Lightbox bileşeni saf JS ile yazılmıştır.
* **SEO & Erişilebilirlik:** Tüm görseller için arama motoru optimizasyonlu (SEO) ve ekran okuyucu uyumlu `alt` etiketleri tanımlanmıştır.
